# 이미지 AI 요청서: 식품 그림 세트

우리 집 냉장고 앱 '냉장고를 부탁해'의 식품 아이콘을 그려 주세요. 지금은 이모지를 쓰고 있어서, 같은 화풍의 한 세트로 바꾸려고 합니다. 폴더·파일 규칙은 `src/assets/food/README.md` 와 같습니다.

## 공통 사양 (모든 그림)

- **512×512 px 정사각 PNG, 투명 배경**으로 받습니다(받은 뒤 우리가 앱용 256×256 으로 줄여 넣어요). 식품이 가운데, 사방 24px 이상 여백
- 앱에 들어가는 파일은 **256×256, 100KB 이하**(미리 받아 두는 오프라인 캐시에 들어가니 가볍게). 그림자·바닥면·글씨·로고 없음
- 파일 이름은 아래 표의 `id` + `.png` (예: `apple.png`)

## 화풍

- 둥글고 부드러운 플랫 일러스트. 윤곽선 없음(또는 아주 얇게), 모서리 둥글게
- 한 그림에 색 3~4가지, 하이라이트 한 점 정도만
- **바질 그린 포인트**: `#1e6b52`(진) 위주, 옅은 `#e3f1ea` 는 작은 면(라벨 띠·잎 안쪽)에만 — 큰 면에 쓰면 연두 타일 바탕에 묻혀요. 꼭지·잎·뚜껑·라벨 띠에 사용해 세트로 보이게
- 식품 본래 색은 유지(사과 빨강, 우유 흰색 등). 채도는 중간, 파스텔 톤
- 정면에서 살짝 위 시점. 병·팩은 서 있게, 낱개 과일·채소는 하나만
- 금지: 실사, 3D 렌더, 사람·손, 브랜드 로고, 한글·영문 글자

## 투명 배경이 안 나올 때

투명 배경을 못 만들면 **순백(#ffffff) 단색 배경**으로 그려 주세요. 우리가 배경을 지워서 넣습니다(그림 안에 흰색 면이 있으면 배경과 구분되게 가는 윤곽선을 둘러 주세요).

## 작게 보여도 알아보기

44px 타일에 들어갑니다. 윤곽 실루엣이 단순하고, 디테일은 2~3개만 남겨 주세요.
