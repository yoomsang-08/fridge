# 식품 그림 폴더 규칙

식품 이름으로 알아본 식품(`src/lib/foodLook.ts` 의 규칙 표)은 이모지 대신 **그림 파일**을 쓸 수 있습니다. 파일이 있으면 그림, 없으면 이모지라서 하나씩 채워도 앱이 깨지지 않습니다.

## 어디에, 무슨 이름으로

- 폴더: `src/assets/food/` (빌드 때 묶이고 해시 주소가 붙어 캐시 걱정이 없습니다. `public/` 이 아닙니다)
- 파일 이름: 규칙 표의 `id` + `.png` (영문 소문자·하이픈). 예: `apple.png`, `soy-sauce.png`, `sweet-potato.png`. 한글 파일명은 쓰지 않습니다.
- 새 식품을 늘릴 때: `foodLook.ts` 에 규칙과 `id` 를 먼저 추가하고, 그다음 그림을 넣습니다.

## 파일 사양

- PNG, **512×512 정사각, 투명 배경**, 식품이 가운데에 꽉 차되 사방 24px 이상 여백.
- 한 장 200KB 이하(PNG 최적화), 그림자·바닥면·글씨 없음.
- 쓰는 곳: 재고 목록 타일(44px)·식품 시트(48px)·'지금 챙길 식품'·2D 평면 동그라미 칩. 타일에서 알아볼 수 있게 **실루엣이 단순**해야 합니다. 3D 이름표는 아직 이모지입니다(다음 단계).

## 그림 지침 (이미지 AI 요청 때 그대로 붙이기)

- 둥글고 부드러운 플랫 일러스트. 윤곽선은 없거나 아주 얇게, 모서리는 모두 둥글게.
- 한 그림에 색은 3~4가지. 하이라이트 한 점만 허용(그라데이션·질감 최소).
- 포인트 색은 **바질 그린**(`#1e6b52`, 옅은 `#e3f1ea`): 꼭지·잎·뚜껑·라벨 띠에 쓰면 전체 그림이 한 세트로 보입니다. 빨강·주황·겨자는 식품 본래 색일 때만.
- 시점은 정면에서 살짝 위(약 15°). 병·팩은 서 있게, 낱개 과일·채소는 하나만(무리 지어 그리지 않기).
- 실사·3D 렌더·사람·손·브랜드 로고·한글/영문 글자 금지.

## 확인

1. 파일을 넣고 `npm run dev` → 재고 목록·냉장고 2D 에서 그림이 보이는지.
2. 흰 바탕·`accent-soft`·분류 `tint` 바탕 위에서 모두 또렷한지.
3. 그림이 없는 식품은 이모지로 나오는지(둘이 섞여도 어색하지 않은지).
